# Security policy

Please report a suspected vulnerability through a private GitHub Security
Advisory for this repository. Do not include save files, credentials, or other
personal data in a public issue.

Supported releases are identified by the latest GitHub release. Reports should
include the affected version, expected behavior, observed behavior, and the
minimum reproduction steps needed to investigate safely.

The in-app updater accepts only stable releases from this repository, verifies
GitHub's SHA-256 asset digest, validates package paths and executable identity,
and applies managed files through a backed-up transaction. Please report any
unexpected update source, digest failure, unsafe archive behavior, or rollback
failure through a private advisory.
